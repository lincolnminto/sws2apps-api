# Scheduling Workbox System (sws2apps) API

[![CD](https://github.com/sws2apps/sws2apps-api/actions/workflows/deploy.yml/badge.svg)](https://github.com/sws2apps/sws2apps-api/actions/workflows/deploy.yml)

Backend service for all sws2apps applications.

## Localization

We support the localization of the email message generated by this API, based on the UI language selected by the user. Translations live in this repository under `src/locales/<locale>/`; English (`src/locales/en/`) is the source of truth. To add or update a translation, edit the JSON file directly and open a pull request.
